# Python Skill Training

Beginner Python practice examples organized by day.

- **Day 01 – Python Basics:** keywords, data types, functions, sets, dictionaries, tuples, indexing/slicing, and exception handling.
- **Day 02 – Control Statements:** string length, character classification, number comparison, vowels, ASCII values, formatted strings, conditionals, and loops.

These are reconstructed practice examples based on topics discussed during training, **not a verbatim copy of the trainer's programs**. Other topics mentioned in class (SQL, HTTP, HTML, CSS, JavaScript, Flask, and Django) are not Python program files in this collection.

## Run a program

Open this folder in VS Code, then use the terminal:

```powershell
python Day-02-Control-Statements/vowel_check.py
```
